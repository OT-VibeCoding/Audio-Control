# オーディオコントロール (Audio-Control)

Windows 11 のクイック設定「音声出力」フライアウトを参考にした、タスクトレイ常駐型のオーディオコントローラーです。
画面の右端にマウスを当てるとパネルがスライド表示され、出力デバイスの切り替えや音量の調整がすぐにできます。

## 主な機能

- 出力デバイスの一覧表示とワンクリック切り替え
- デバイス全体の音量・ミュート操作（％表示つき）
- アプリごとの音量ミキサー（％表示・ミュート切り替え）
- 画面右端ホバーでパネルをスライド表示（マルチモニタ対応）
- マウスがパネルから離れると自動で閉じる（判定の余白は調整可能）
- 表示項目数に合わせてパネルの高さを自動調整
- トレイメニューから右端ホバーの「停止」と、スタートアップ（自動起動）の登録・解除
- 高DPI対応
- 動作確認用の自己診断モード（`--check`）

## 動作環境

- Windows 11
- Python 3.x（3.14 で動作確認）
- 依存ライブラリ: pycaw / comtypes / pystray / Pillow

## インストール

```
py -m pip install -r requirements.txt
```

## 使い方

起動（コマンドプロンプトにログが表示されます）:

```
py audio_sidebar.py
```

黒いコマンドプロンプト窓を出さずに起動する場合:

```
pyw audio_sidebar.py
```

オーディオ機能の動作確認だけを行う場合:

```
py audio_sidebar.py --check
```

### 操作

- 画面右端にマウスを少し留めるとパネルが表示されます
- トレイアイコンをクリックしても表示できます
- トレイアイコンの右クリックメニュー
  - **パネルを開く**
  - **停止**: 右端ホバーによる自動表示を止めます（トレイ常駐は継続）
  - **スタートアップに登録**: Windows 起動時の自動起動を切り替えます
  - **終了**

## 設定

`audio_sidebar.py` 上部の定数で挙動を調整できます。

| 定数 | 内容 |
| --- | --- |
| `EDGE_INSTANT` | `True` で右端に触れた瞬間に表示 |
| `EDGE_DWELL_MS` | 右端に何ミリ秒留まったら表示するか |
| `EDGE_TRIGGER_PX` | 右端から何ピクセル以内で反応するか |
| `EDGE_SCREEN` | `"any"` = 全モニタ / `"primary"` = メインモニタのみ |
| `CLOSE_ON_LEAVE` | `True` = マウスが離れたら閉じる / `False` = 外側クリックで閉じる |
| `CLOSE_MARGIN_RATIO` | 閉じる判定の余白（パネルサイズに対する割合） |
| `CLOSE_ANIMATE` | 閉じるときのスライドアニメの有無 |

## 注意事項

- スタートアップ登録は、登録時のファイルの場所を記録します。ファイルを移動した場合は、一度登録を解除してから再登録してください。
- 多重起動の防止機能はありません。手動起動と自動起動が重ならないようにしてください。
